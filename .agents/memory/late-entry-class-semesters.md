Class creation and editing must ask for the starting semester. A newly managed cohort can begin at a later program semester; do not force Semester 1, infer progression from session dates, or manufacture earlier semester records. Once real history exists, preserve it and continue after the latest recorded semester.

**Why:** The user identified a newly entered BS Accounting & Finance 2022–26 cohort that needs to start Semester 8 despite having no earlier semesters in this system.

**How to apply:** Keep first-managed semester separate from program length and numbering. Respect the Bridging program range of 5–8, use the configured start for empty cohorts, and never erase history or move the start later than the first real recorded semester.
