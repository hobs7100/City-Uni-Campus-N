name: Semester attendance baseline
description: User-requested initial attendance percentage for each new semester.
---

Every semester's starting student attendance value is 100%. Keep the same institute attendance policies for warnings and struck-off decisions.

**Why:** The user requested “JUST minor change that each semester starting seed value should be 100% of students attendance.”

**How to apply:** Treat 100% as the baseline when there are no evaluable present/absent marks in that semester, including leave-only windows. Once marks exist, calculate the real percentage normally; do not insert artificial present records, carry forward old-semester percentages, change protection periods or thresholds, or automatically reactivate an already struck-off student.
