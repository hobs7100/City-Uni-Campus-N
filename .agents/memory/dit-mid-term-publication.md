---
name: DIT Mid-Term publication
description: Administrative release requirement for DIT Mid-Term test-series results.
---

DIT results for the test series named “Mid-Term” must remain hidden from students until an admin uses “Announce Mid Result.” Teachers still enter and review their relevant course results normally.

**Why:** The user explicitly requires an administrative announcement before students receive their DIT Mid-Term marks; uploading marks is not publication.

**How to apply:** Enforce visibility server-side, including student dashboard/chart data and filter options, not only in the results table. Do not change other test-series visibility or non-DIT examination flows. Keep repeated announcements safe and preserve the original announcing admin and time.
